# risshisha-javascript

## English
This repository contains JavaScript practice exercises and examples, organized by topic and lesson. Each folder includes an `index.html` and `main.js` file to demonstrate the concepts.

### Lesson folders
- `02_basics/` — Basic JavaScript syntax, variables, expressions, and simple logic.
- `02_array/` — Array creation, indexing, iteration, and basic array operations.
- `02_arrow_function/` — Arrow function syntax and how it differs from traditional functions.
- `02_callback_function/` — Callback functions and using functions as arguments.
- `02_do_while/` — `do...while` loops and loop execution at least once.
- `02_for/` — Standard `for` loop usage for repeated tasks.
- `02_for_each/` — Array iteration with `forEach` and callback-based looping.
- `02_for_of/` — Modern `for...of` loops for iterable objects.
- `02_function/` — Declaring and calling regular functions.
- `02_function_constructor/` — Function constructors and object creation patterns.
- `02_function_literal/` — Function literals and inline function definitions.
- `02_function_exercises/` — Practice exercises focused on functions.
- `02_js_exercises/` — Miscellaneous JavaScript exercises and small projects.
- `02_manipulating_arrays/` — Common array manipulation techniques and methods.
- `02_nestingloop/` — Nested loops and working with multi-dimensional iteration.
- `02_object/` — JavaScript objects, properties, and simple object use.
- `02_object_method/` — Object methods and using functions inside objects.
- `02_while/` — `while` loops and condition-based repetition.

## 日本語
このリポジトリには、トピック別に整理された JavaScript の練習問題とサンプルが含まれています。各フォルダには、概念を示すための `index.html` と `main.js` が含まれています。

### レッスンフォルダ
- `02_basics/` — 基本的な JavaScript の構文、変数、式、シンプルなロジック。
- `02_array/` — 配列の作成、インデックス、反復処理、基本的な配列操作。
- `02_arrow_function/` — アロー関数の構文と従来の関数との違い。
- `02_callback_function/` — コールバック関数と関数を引数として使う方法。
- `02_do_while/` — `do...while` ループと少なくとも一度実行するループ。
- `02_for/` — 繰り返し処理に使う標準的な `for` ループ。
- `02_for_each/` — `forEach` を使った配列反復とコールバックベースのループ。
- `02_for_of/` — イテラブルなオブジェクトのための最新の `for...of` ループ。
- `02_function/` — 通常の関数の宣言と呼び出し。
- `02_function_constructor/` — 関数コンストラクタとオブジェクト生成パターン。
- `02_function_literal/` — 関数リテラルとインライン関数定義。
- `02_function_exercises/` — 関数に焦点を当てた練習問題。
- `02_js_exercises/` — さまざまな JavaScript 演習と小さなプロジェクト。
- `02_manipulating_arrays/` — よく使う配列操作のテクニックとメソッド。
- `02_nestingloop/` — ネストしたループと多重反復処理。
- `02_object/` — JavaScript のオブジェクト、プロパティ、基本的なオブジェクトの使い方。
- `02_object_method/` — オブジェクトメソッドとオブジェクト内の関数の使用。
- `02_while/` — `while` ループと条件に基づく繰り返し処理。
